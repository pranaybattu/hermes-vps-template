Privacy policy — Hermes Mnemosyne Backup

This personal tool requests Google's drive.file scope to create, read, update, and delete backup files and their metadata within the access granted to this app. That access is used only for backup and restoration.

Restic encrypts database backups before upload to Google Drive. OAuth credentials are stored in the owner's local rclone configuration and, when CI is configured, GitHub Actions environment secrets. GitHub Actions processes the database snapshot during backup and sends encrypted backup data to Google Drive.

Data is not sold, used for advertising, or shared for unrelated purposes. Google and GitHub process data as needed to provide storage and workflow services. Backups remain until the owner deletes them or applies a retention policy.

The owner can revoke this app in Google Account permissions, remove stored OAuth credentials, and delete its backup files in Drive. Revoking access does not delete existing backups.

For support, use the support email displayed on the Google OAuth consent screen.
